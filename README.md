## Brief Summary
During this assignment, I learned how to combine pure CSS Media Queries and Bootstrap's built-in responsive classes. I understood how breakpoints work and how to manage column widths using the 12-column grid system in Bootstrap. The hardest part was calculating percentages for Task 1, but using `calc()` and flexbox solved the issue. The project runs without errors in the browser.
